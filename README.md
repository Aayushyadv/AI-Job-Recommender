# 🤖 AI Job Recommender

An AI-powered job recommendation system that helps users find suitable jobs based on their skills, experience, job title, location, and preferences.

## 🚀 Features

- 🎯 Job Recommendations
- 🔍 Search and filter jobs
- 🧠 AI-based job matching
- 📄 Resume Analyzer
- 🛠️ Skill Gap Analysis
- 🧭 Career Roadmap
- 📊 Job Market Dashboard
- 🤖 AI Job Assistant
- 📍 Location and work-type filters

## 🧠 How It Works

The system uses NLP and Machine Learning techniques to recommend relevant jobs.

### Recommendation Process

Job Information  
↓  
Data Cleaning  
↓  
Text Processing  
↓  
TF-IDF  
↓  
Cosine Similarity  
↓  
Job Ranking  
↓  
Recommended Jobs

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly
- NLP
- TF-IDF
- Cosine Similarity

## 📄 Resume Analyzer

Users can upload their resume and get information such as:

- Candidate name
- Skills
- Resume content
- Relevant job recommendations

The system supports PDF and DOCX resumes.

## 📊 Dashboard

The dashboard provides information about:

- Total jobs
- Companies
- Locations
- Skills
- Experience levels
- Work types
